# RabbitMQ vs Redis Benchmark

## Run
docker-compose up -d

Run producer and consumer separately.

## Params
- benchmark.rate
- benchmark.payload-size
- benchmark.broker = rabbit | redis

## Отчет
Результаты показали, что:

RabbitMQ обеспечивает более стабильную пропускную способность и практически не увеличивает задержки при росте нагрузки.
Redis демонстрирует худшую производительность при увеличении размера сообщений, особенно при 10KB payload.
При высокой нагрузке Redis показывает значительные скачки задержек (до 1284 ms), что свидетельствует о деградации системы.
RabbitMQ не достиг точки деградации в рамках проведенных тестов.

Таким образом:

RabbitMQ лучше подходит для систем с высокой нагрузкой и требованиями к надежности.
Redis может использоваться для легковесных сценариев с небольшими сообщениями и низкими требованиями к стабильности.
